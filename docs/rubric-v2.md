## 三件要业务侧拍板的事

**截图算不算取证。** 27B prompt 写明语音通道不得要求截图，但标注员的 J 列反复把
「请提供截图」写成正确答案，`truth.jsonl` 68 条里有 8 条含「截图」。v2 按 prompt
口径定义 `neg_3_1` 与取证率 —— 口径定下来后要清一遍 truth，否则 T1 会惩罚做对了的回答。

**越权表态是 D 级还是 severe。** 标注指南定为 D 级，但这批 95 条一个 D 都没打，
合并后的 `neg_4_1` 只有 n=5、C率 40%。v2 暂按数据给 severe。

**权重档位一处定义。** C率 ≥90% hard_fail · 40–89% severe · <40% normal。
v1 的 docstring 与 selftest 写的是两套边界，v2 统一。
